# Автосалон PRO — Веб-приложение

Полноценное веб-приложение для управления автосалоном с базой данных SQLite и админ-панелью.

## Возможности

- **Каталог автомобилей** — просмотр, фильтрация по марке и цене
- **Админ-панель** — управление автомобилями, клиентами, сделками
- **Загрузка изображений** — добавление фото для каждого автомобиля
- **Отчёты** — аналитика продаж, выручка, популярные модели
- **Адаптивный дизайн** — работает на всех устройствах

## Технологии

- **Python + Flask** — backend
- **SQLite** — база данных
- **HTML/CSS/JS** — frontend
- **Font Awesome** — иконки

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
python app.py
```

Приложение запустится на `http://localhost:5000`

### 3. Вход в админ-панель

Перейдите на `http://localhost:5000/admin/login`

- **Логин:** `admin`
- **Пароль:** `admin123`

## База данных

Таблицы:
- **users** — пользователи админ-панели
- **cars** — автомобили (марка, модель, год, цена, VIN, двигатель, цвет, фото, статус)
- **clients** — клиенты (ФИО, телефон, email, паспорт)
- **deals** — сделки (автомобиль, клиент, сумма, способ оплаты, дата, номер договора)

## Развёртывание

Для продакшена рекомендуется использовать:
- **Gunicorn** как WSGI-сервер
- **Nginx** как обратный прокси
- **PostgreSQL** вместо SQLite для больших нагрузок
